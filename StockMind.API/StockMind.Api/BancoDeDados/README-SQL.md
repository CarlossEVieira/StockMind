# Scripts SQL - StockMind

Este diretório contém os scripts SQL utilizados no projeto StockMind.

## Objetos criados

### View

vwProdutosEstoqueBaixo

Responsável por listar os produtos com estoque abaixo do mínimo definido.

### Stored Procedure

spListarProdutosBaixoEstoque

Retorna os produtos em situação crítica de estoque.

### Function

fnTotalProdutosBaixoEstoque

Retorna a quantidade total de produtos com estoque abaixo do mínimo.
